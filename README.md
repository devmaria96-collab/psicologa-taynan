# 🧠 Site Institucional — Taynan Azevedo | Psicóloga

Site institucional desenvolvido para apresentar o trabalho da psicóloga Taynan Azevedo, reunindo informações profissionais, abordagem terapêutica, disponibilidade para atendimento e canais de contato em uma experiência digital acolhedora e intuitiva.

## ✨ Sobre o projeto

O projeto tem como objetivo oferecer uma presença digital profissional para a psicóloga, com um layout elegante, navegação intuitiva e adaptação para diferentes dispositivos.

A identidade visual utiliza tons terrosos, cores suaves e tipografia elegante, buscando transmitir acolhimento, tranquilidade e profissionalismo.

## 🚀 Funcionalidades

- **Página inicial:** apresentação da psicóloga.
- **Sobre mim:** apresentação da trajetória profissional com carrossel de imagens.
- **Meus serviços:** apresentação dos serviços oferecidos.
- **Abordagem terapêutica:** informações sobre a Terapia de Aceitação e Compromisso (ACT).
- **Contato:** acesso aos canais de comunicação.
- **Disponibilidade para atendimento:** visualização dos dias e períodos disponíveis.
- **Integração com WhatsApp:** acesso direto para iniciar uma conversa.
- **Integração com Instagram:** acesso ao perfil profissional.
- **Contato por e-mail:** link para iniciar uma mensagem.
- **Design responsivo:** adaptação para computadores, tablets e celulares.

## ⚙️ Como executar o projeto

### Pré-requisitos

- Node.js instalado.
- npm instalado.
- Git instalado.

### 1. Clone o repositório

```bash
git clone https://github.com/devmaria96-collab/psicologa-taynan.git
```

### 2. Acesse a pasta do projeto

```bash
cd psicologa-taynan
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Execute a aplicação

Confira os scripts disponíveis no `package.json`. Se o projeto possuir o script `dev`, execute:

```bash
npm run dev
```

### 5. Acesse no navegador

Normalmente, a aplicação estará disponível em:

```text
http://localhost:3000
```

Verifique o endereço indicado no terminal caso a porta padrão esteja ocupada.
